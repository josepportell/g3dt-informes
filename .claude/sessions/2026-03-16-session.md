## Adjacents Root Cause Analysis

**Problem**: Wizard shows generic "parcel·la amb construcció" instead of proper street names/descriptions for Bell-Lloc adjacents.

**Root cause**: DPSH GPS coordinates (314418.9, 4611117.6) resolve to cadastral parcel "Via Ferrea 57" — the WRONG parcel, ~105m from actual project at "Carrer Mestre Ramon Ortiz".

**Why geocoding also fails**: "Carrer Mestre Ramon Ortiz" is a new street. Exists in cadastre DB (cv=130) but has no numbered parcels yet. Nominatim/OpenStreetMap don't know it.

**Why `/g3dt-adjacents-visor` wouldn't help either**: It starts from the same wrong UTM coords → navigates to wrong parcel on the map.

**Conclusion**: Not a code bug. For new development areas with inaccurate GPS, Eva needs to provide correct UTM coords or referència catastral, or manually edit adjacents in the wizard.

**Future improvement**: Add warning in wizard when cadastre LDT doesn't match planol street_address (would catch coordinate mismatches early).
