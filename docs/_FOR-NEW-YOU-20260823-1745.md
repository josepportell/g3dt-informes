## 4. Protocol de la lectura d'or (el que serà el skill)

Per projecte (ordre: **Bell-lloc** primer — el més complet —, després **Tulipa** — el més difícil —, després la resta):

1. Inventari: tots els fitxers, adjunts de `.msg` extrets (`extract_msg` al venv), `.zip` obert (Tulipa: 3 `.dwg`; si no hi ha
   conversor, marca'ls "no llegible: DWG" i proposa `dwg2dxf` com a tasca), subcarpetes `{YY.NNNN}/`, `ACCEPTACIO/`, `FOTOGRAFIES/`.
   **Exclou** sortides de l'Eva i nostres: `*_informe*`, `*_generated*`, `*portada*`, `PDF/LLETRA`, `PDF-V0`, `PDF V0`, `.FH11`,
   `validation/`, `_validation/`. **Inclou** `PDF/ANNEXES/*_sondeig.pdf`, `tall.pdf`, `pl situ.pdf` (annexos: fonts vàlides).
2. Per cada font, en aquest ordre: plantilles G3 (pressupost, fitxa, comanda, PLAN_COST, Excel DPSH) → annexos de l'Eva →
   documents del proveïdor (plànols, projectes, correus) → fulls de camp manuscrits → fotos. Llegeix-lo SENCER (totes les pàgines;
   `Read` accepta PDFs amb `pages`, màx 20 per crida; Excel i `.msg` per Python) i escriu **un JSON per font**:
   ```
   {"source_path": "...", "document_type": "pressupost_g3|fitxa_camp_g3|comanda_lab_g3|plan_cost_g3|dpsh_excel|annex_sondeig|
                     planol|projecte_arquitecte|correu|foto|full_camp_manuscrit|altre",
    "what_it_is": "1 frase", "issuer": "...", "date": "...", "pages_or_sheets": N,
    "tier_a": [{"concept_id": "...", "value": "...", "location": "p.1 / full 'fitxa' B5 / cos del correu / adjunt X p.2",
                "quote": "text literal", "confidence": 0.0-1.0, "note": "ambigüitat, conflicte, llengua"}],
    "not_present": ["concept_id", ...],   # camps del nivell A que has buscat i no hi són
    "reading_notes": "què ha calgut fer (zoom, 2a lectura, girar pàgina…)"}
   ```
3. Al final del projecte, `_decisions.json`: per cada un dels 15 camps, `status` (segur/candidats/no_trobat), `value`,
   `candidates[]` (valor, font, cita), `rule` (quina regla de §3 has aplicat), `sources_checked[]`.
4. Després — i només després — compara amb `eva_reference_values.json` + el truth-map del projecte. Classifica cada camp:
   OK / CAND / NT / **ERR**. Cada ERR és una regla que falta al skill: escriu-la.
5. Actualitza el skill (`.claude/commands/g3dt-llegir-projecte.md`, nou) amb el que has après. El skill ha de ser executable
   headless: prompt autocontingut, sense preguntes, sortida = els JSON de dalt.

**On escriure:** els JSON a `docs/golden-read/{expedient}/` dins del repo (commitables, verificables). Mai a
`reference-material/` (regla) ni a `/mnt/c/claude/g3dt/projectes/*/validation/` (cache del pipeline; `eva_reference_values.json`
dels 7 de referència és a `reference-material/*/validation/`, les còpies de `/mnt/c` no el tenen).

**Context:** les imatges costen finestra. Escriu el JSON de cada font immediatament (el disc és la memòria), i per als projectes
grans (Anciles 35 pàgines de plànols, Castellar 30 imatges) delega la lectura d'un document a un subagent que retorni el JSON;
tu conserves les decisions. Això reprodueix millor la forma headless de producció (una crida per document).
