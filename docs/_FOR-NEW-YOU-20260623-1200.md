## 4. The OBRA parser (Via A) — algorithm
Replace the `EMPLAÇAMENT` regex. From the first `OBRA:` line, collect non-empty lines until an end marker (line ending `:` like `CLIENT:`/`CP I POBLACIÓ:`, or a budget code like `26·0332`). Find the project-type line (`^ESTUDI[O]?\s+GEO`). The lines AFTER it up to the marker = `[street?, municipality]`; **last = municipality**, anything before = street.
