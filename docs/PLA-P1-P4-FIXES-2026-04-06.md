## Phase 1: P3 — Lab Extraction (~56 NOT_EXTRACTED)

### What
Wire 8 lab_* variables into the pipeline. Data exists in GTL report PDFs but isn't output.

### Key Finding
- `lab_extractor.py` already extracts sample_info (location, sample_id, depth) via regex but DOESN'T return it to the pipeline
- Pipeline reads `lab_results_pdf` (LAB-SIG.pdf) but NOT `gtl_report` (e.g., 4677-GTL-25.pdf) which has the full sample metadata
- 4 of 8 variables are constants/templates (company name, description) — identical across all projects
- Lab company is always "TPS PROSPECCIÓ DEL SUBSÒL SL" (visible on left margin of GTL PDFs)
- Lab descriptions are fixed text by language (CA/ES)

### GTL PDF Structure (Soilassaig format, consistent)
```
PAGE 1: Header
  - Soilassaig logo
  - Report number: 4677-GTL-25
  - Client: G3 Desenvolupament Territorial, SL (always the same)
  - Material: Sòl
  - Situació: Bell-Lloc d'Urgell. Carrer Antoni Bellet.
  - Lab ref: GTL-8205-25
  - Left margin: "TPS, PROSPECCIÓ DEL SUBSÒL, SL" (vertical text)

PAGE 2: Sample Data
  - Mostra: SPT1 S1              → lab_sample_id
  - Cota d'extracció (m): 1,0-1,6 → lab_depth
  - Obra/Projecte: location + ID
  - ASSAIGS REALITZATS: test list  → lab_tests_text

PAGE 3+: Results
  - Sulfate, granulometry, Atterberg, etc.
```

### Steps
1. Add 8 lab_* concept definitions to `schemas/concepts/report_variables.yaml`
2. Extend `lab_extractor.py`:
   - Add `_find_gtl_pdf()` to find GTL reports via `gtl_report` role in file_mapping.json
   - Return sample metadata (location, sample_id, depth) that's already extracted
   - Extract lab_tests_text from "ASSAIGS REALITZATS" section
   - Hardcode/template: lab_field_company, lab_testing_company, lab_field_description, lab_testing_description
3. Wire into `auto_extractor.py` `_phase2_lab_results()` — capture all lab fields, not just sulfate

### Variables
| Variable | Source | Method |
|----------|--------|--------|
| lab_field_company | GTL p1 margin | Hardcode "TPS PROSPECCIÓ DEL SUBSÒL SL" |
| lab_testing_company | same | Same as above |
| lab_field_description | fixed | Template by language (CA/ES) |
| lab_testing_description | fixed | Same as above |
| lab_location | GTL p2 "Mostra" | Regex (already coded, not output) |
| lab_sample_id | GTL p2 "Mostra" | Regex (already coded, not output) |

| lab_tests_text | GTL p2 "ASSAIGS REALITZATS" | Regex (new) |
| access_street | NOT in GTL | DEFERRED (narrative template) |

### Files

- `automation/lab_extractor.py`
